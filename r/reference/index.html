    R function reference¶

    Generated from the package's roxygen comments by docs-site/_tools/gen_r_reference.py. The R functions mirror the Python API (m.ecosim(...) is ewe_ecosim(m, ...)); the Python pages explain the options in more depth.

    Models, Ecopath and Ecosim¶

    ewe_open¶

    ewe_open(path, engine = NULL)

    Open an EwE model

    Argument
    path Model file: .eiixml, or an EwE Access database (.ewemdb/.mdb), which is converted to .eiixml first when not on Windows.
    engine Optional path to ewe-engine(.dll).

    Returns: An ewe_model. Close it with ewe_close().

    ewe_ecosim¶

    ewe_ecosim(m, scenario = NULL, years = NULL, effort = NULL, vulnerability_multiplier = NULL, fleets = TRUE)

    Run an Ecosim scenario

    Argument
    scenario 1-based index or name; defaults to the first scenario.
    years Override the number of years.
    effort Named numeric: fleet name -> multiplier on that fleet's whole effort series.
    vulnerability_multiplier Scale every predator-prey vulnerability.
    fleets Include the catch-by-fleet table.

    Returns: A list: scenario, years, groups and fleets (long, monthly), summary, messages (warnings from the run).

    ewe_add_group¶

    ewe_add_group(doc, name, type = "consumer", ..., before = NULL, detritus_fate = NULL)

    Add a functional group

    Argument
    name Unique group name.
    type "consumer", "producer", "detritus", or a number between 0 and 1 for a partial producer.
    ... Group fields, e.g. biomass_area = 2, pb = 0.8, qb = 4. NA means "not entered".
    before Insert before this group. By default living groups go after the last living group and detritus at the end (Ecopath needs living groups first).
    detritus_fate Named numeric, detritus group -> proportion. By default everything goes to the first detritus group; living groups added before any detritus group get that default when the first detritus group is added.

    ewe_calculate_stanzas¶

    ewe_calculate_stanzas(doc, apply = TRUE)

    Run EwE's multi-stanza calculation As the desktop app does when stanza parameters change: from the leading stage's B and Q/B, each stage's Z (mortality), von Bertalanffy K (vbk) and wmat_winf, derives B of every other stage and Q/B of every stage but the leading Q/B stage (those may be NA before the call).

    Argument
    apply Write the results into the document's groups.

    Returns: list(doc, stages): the (updated) document and one row per life stage.

    ewe_set_effort(doc, scenario, fleet, values, interval = c("year", "month"))

    Argument

    Add an annual time series to a dataset (created if needed) On save, a dataset in the document replaces the model's dataset of the same name; others stay.

    Argument

    ewe_fit¶

    ewe_fit(m, dataset, scenario = NULL, vulnerabilities = TRUE, anomaly_spline_points = 0L, anomaly_shape = NULL, reset_vulnerabilities = FALSE, max_iterations = NULL)

    Fit Ecosim to a time series dataset Runs EwE's "Fit to time series" search. Nothing is stored in the model; keep the result with ewe_fit_save() or ewe_fit_apply().

    Argument
    dataset Time series dataset, 1-based index or name.
    vulnerabilities Search vulnerabilities, one block per predator with reference data.
    anomaly_spline_points Also search a primary production anomaly with this many spline points (1 = one value per year).
    anomaly_shape Forcing function (1-based index or title) to hold the anomaly. By default a new one titled "PP anomaly (fit)", or the existing one with that title. It is applied to the production rate of every producer.
    reset_vulnerabilities Start from EwE's default vulnerability (2), like the desktop app's "Use default v" option. Off by default, so the search refines the scenario's own vulnerabilities. The result keeps the best parameters the search tried, and messages warns when the fit still scores worse than the scenario as stored.
    max_iterations Stop the search early.

    Returns: A list: ss_before, ss_after (with the fitted values, as the scenario runs once saved), aic, iterations, vulnerabilities (before/after per link) and, with an anomaly search, anomaly_shape and anomaly (month, year, value).

    ewe_fit_save¶

    ewe_fit_save(m, fit, path, reopen = TRUE, only_changed = FALSE)

    Keep a fit: save it with the model, or load it into the session ewe_fit_save() writes the model as .eiixml with the fitted vulnerabilities and anomaly stored in the fit's scenario, where the EwE desktop app keeps them. The anomaly is a forcing function applied to the production rate of every producer; forcing functions are shared by all scenarios of a model. The session continues on the saved file unless reopen = FALSE. ewe_fit_apply() loads the fitted values into the session so later runs use them, without writing the original file.

    Argument
    fit The result of ewe_fit().
    only_changed Write only the links the search changed (by default all links, since reset_vulnerabilities also changes links outside the searched blocks).

    Returns: ewe_fit_save(): the path written, invisibly. ewe_fit_apply(): a list with vulnerabilities_written and anomaly_shape, invisibly.

    ewe_fit_apply(m, fit, only_changed = FALSE)

    ewe_monte_carlo¶

    ewe_monte_carlo(m, trials = 10L, scenario = NULL, seed = NULL, years = NULL, dataset = NULL)

    Ecosim Monte Carlo Resamples Ecopath inputs within their CVs, rebalances, and runs Ecosim for each trial.

    Argument
    trials Number of trials.
    seed Random seed, for repeatable trials.
    years Override the scenario length.
    dataset Time series dataset to score each trial against.

    Returns: A list: trials (sum of squares), inputs (sampled Ecopath inputs) and biomass (start/end per trial and group).

    ewe_ecotracer(m, scenario = NULL, tracer_scenario = NULL, years = NULL)

    Returns: A list with concentrations: step, time, group, concentration, concentration_per_biomass. The group "(environment)" is the concentration in the environment.

    ewe_ecospace¶

    ewe_ecospace(m, space_scenario = NULL, scenario = NULL, years = NULL, maps = TRUE)

    Management¶

    ewe_mse¶

    ewe_mse(m, trials = 10L, scenario = NULL, seed = NULL, years = NULL, parameters = NULL, groups = NULL, fleets = NULL, trial_values = FALSE)

    Management Strategy Evaluation Runs EwE's closed-loop MSE: stochastic trials of assessment, harvest rules and Ecosim.

    Argument
    trials Number of trials.
    seed Random seed, for repeatable trials.
    years Override the scenario length.
    parameters Named list of MSE parameters, e.g. list(regulatory_mode = "NoRegulations").
    groups Named list: group name (or index) to MSE group settings, e.g. list(Cod = list(fixed_f = 0.2)).
    fleets Named list: fleet name (or index) to MSE fleet settings, e.g. list(Trawlers = list(quota_type = "Weakest")).
    trial_values Also return every trial's yearly values.

    Returns: A list: groups and fleets (summary statistics), value, yearly (year, variable, name, mean, q05, q50, q95), the settings used, and trial_values when asked.

    ewe_msy¶

    ewe_msy(m, target = NULL, mode = "group", scenario = NULL, max_rel_f = NULL, steps = NULL, trial_years = NULL, to_depletion = FALSE)

    Equilibrium yield curves (MSY) Varies the F of one group (or the effort of one or all fleets) and runs Ecosim to equilibrium at each step, under full compensation and a stationary system.

    Argument
    target Group (group mode) or fleet (fleet mode; NULL for all fleets), by name or index.
    mode "group" or "fleet".
    max_rel_f Highest F as a multiple of the target's base F (group mode), or highest effort multiplier.
    steps Number of equal F steps between 0 and the highest F.
    trial_years Years Ecosim runs at each F.
    to_depletion Keep raising F until the catch is depleted.

    Returns: A list: curve (assessment, f, total_value, group, biomass, catch, fishing_mortality), optimum and baseline.

    ewe_fmsy¶

    ewe_fmsy(m, scenario = NULL, max_rel_f = NULL, steps = NULL, trial_years = NULL)

    FMSY of every fished group EwE's "Find FMSY": an MSY search per fished group, then all groups fished at their FMSY at once.

    Returns: A list with groups: assessment, group, f_base, fmsy, found, catch_base, msy, value_base, ...

    ewe_policy_search¶

    ewe_policy_search(m, scenario = NULL, years = NULL, weights = NULL, parameters = NULL, groups = NULL, fleets = NULL, blocks = NULL, max_evaluations = NULL)

    Fishing policy search Searches fleet effort multipliers that maximise a weighted objective (net economic value, social, mandated rebuilding, ecosystem structure, biodiversity).

    Argument
    weights Named list of objective weights, e.g. list(economic_weight = 1, ecosystem_weight = 0.5).
    parameters Named list of search parameters, e.g. n_runs, init_option, discount_rate.
    groups,fleets Named lists of per-group / per-fleet objective settings.
    blocks Named list: fleet to one block code for all years, or one code per year. Fleets sharing a code share one multiplier; 0 leaves a fleet out.
    max_evaluations Cap on objective evaluations.

    Returns: A list: result (objective and its parts), blocks and effort (multipliers found), fleets, progress, and the settings used.

    ewe_mse_wide¶

    ewe_mse_wide(mse, variable = "biomass", stat = "mean")

    One column per group (or fleet) of a yearly MSE statistic

    Argument
    mse The result of ewe_mse().
    variable One of the yearly variables: biomass, catch, fleet_catch, effort, value.
    stat mean, q05, q50 or q95.

    Returns: A data.frame: year and one column per name.

    ewe_yield_curve¶

    ewe_yield_curve(msy, group = NULL, assessment = "full_compensation")

    Yield curve of one group from an MSY run

    Argument
    msy The result of ewe_msy().
    group Group; the MSY target by default.
    assessment "full_compensation" or "stationary_system".

    Returns: F against equilibrium biomass, catch and total value.

    Network analysis and indicators¶

    ewe_network_analysis¶

    ewe_network_analysis(m)

    Network analysis of the Ecopath model

    Returns: A list of data frames: summary (indicator, value, unit: throughput, cycling, path lengths, ascendency, transfer efficiencies, primary production), ascendency (by source), groups (trophic level, ascendency terms, keystoneness, primary production required, L index, Psust), trophic_levels, decomposition (trophic level decomposition) and mixed_trophic_impacts (impacting, impacted, impact).
